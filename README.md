# Portfolio

AI Engineer portfolio built with Next.js (App Router), TypeScript, and CSS.

## Features

- **Bilingual Support**: Instant toggle between English and Spanish.
- **Responsive Layout**: Minimalist interface with dedicated mobile navigation drawer.
- **Accessibility**: Native semantic dialogs, accessible keyboard trapping, and zero layout shift.
- **Technical Rigor**: Fully verified with strict TypeScript types, ESLint, automated security tests, and HTTP headers verification.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build & Verification

```bash
npm run build
npm run verify
```
